# SYNTHETIC_TEST_FIXTURE_ONLY

Every file in this directory is synthetic test data generated by `cloudleak demo`. Account IDs, resource names and amounts are invented.

From this directory, run `cloudleak reconcile m1 --invoices invoices.csv` to compare the September exports with the synthetic invoices. Each invoice total is rounded to cents after summing the billed amounts. The default comparison preserves any sub-cent difference.
